## About the Project

This **Portfolio** serves as a professional showcase and interactive technical laboratory. Built with semantic HTML5, modular CSS3, and vanilla JavaScript, the project highlights my practical experience in back-end architecture, information security, and infrastructure automation, combining technical rigor with a personalized visual experience.

---

## Features and Sections

### Landing Page & Presentation
- Visual identity focused on **Software Engineering**, **Back-end**, and **DevSecOps**.

- Dynamic theme switcher: Corporate Mode = Dark Mode; Hacker Mode = Light Mode.

- Interactive graphic effect with a trail of glitter particles following the mouse cursor.


### Trajectory & Engineering (About Me)
- Highlight on the transition and synergy between **9+ years of experience in technical support/customer care** and my degree in **Computer Engineering**.

- Focus on **Java/Spring Boot** architecture, **Python** automation, and security in the Software Development Life Cycle (SDLC).

- Key Pillars:

- **DevSecOps & Cybersecurity:** Automation in the deployment pipeline and secure secrets management.

- **Access Management:** Credential control, principle of least privilege, JWT tokens, and restricted CORS.


### Technical Panels

**Continuous Learning & Projects**

This portfolio was designed under the principle of **scalability and continuous improvement**. The application and its ecosystem constantly evolve as new studies, certifications, and architectures are incorporated.

The interface features visual cards to represent different aspects of technical work, such as:

- Security posture;

- CI/CD pipeline;

- Infrastructure;

- Code quality.


These elements serve a primarily **visual and demonstrative** purpose, acting as a way to summarize technologies and practices used in my projects and track my progress with them.

### Threat Intelligence — Simulation

The portfolio features a visual section inspired by Threat Intelligence dashboards.

It presents an **illustrative simulation**, containing:

- World map;

- Origin and destination cities;

- Simulated events;

- Different threat types;

- Traffic animations;

- Event indicators;

- Counters;

- Activity feed.


⚠️ **This is not a real monitoring tool!**

The displayed events are generated locally for visual demonstration purposes and do not represent real attacks, incidents, or security data.

This section exists to visually explore concepts related to monitoring and security within the portfolio's identity.

## Development: Human Authorship vs. AI Support

Unlike purely automated approaches, this repository is the result of a predominantly human process, in which Artificial Intelligence acted strictly as a supporting assistant for time optimization.

## What was done by me (Human Engineering and Implementation)

- Architecture & Structuring: Decision and organization of the modular file structure (CSS variables, layout files, and separate components).

- Interaction Logic (Canvas): Original development of the interactive particle effect (glitter) on the mouse cursor, with logic structured from the base of the interactive map.

- Content & Curation: Full writing of experiences, synthesis of technical trajectory, and definition of the presented professional vision.

- Code Logic and Refactoring:

- Manual CSS adjustments to ensure contrast, smooth transitions, color palette, and correct responsive adaptation for mobile devices.

- Layout bug fixes and layer overlap handling (z-index).

- Adjustments to HTML5 semantics and accessibility.


  ## What was assisted by Generative AI
- Boilerplate and Base Logic: Generation of initial HTML/CSS structures and logical drafts of the Canvas API (which served as a foundation for me to develop and refine the final interactive effects, such as the map and glitter).

- Troubleshooting and Refactoring: Acting as an interactive "Rubber Duck" to debug layout issues (CSS, z-index, responsiveness) and optimize JavaScript snippets.

- Copywriting and Proofreading: Support in professional structuring, polishing, and clarity of the portfolio's descriptive texts, ensuring assertive technical communication (including the formatting of this README itself).
